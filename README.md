# SmartDesk 🧰

SmartDesk is an AI-powered IT support mobile application designed to help users troubleshoot common technical issues before submitting a support ticket.

The goal is to reduce repetitive IT requests by guiding users through clear, step-by-step solutions using AI.

---

## 🚀 Why I Built This

While working in an IT environment, I noticed that many support tickets were for simple, repetitive issues (Wi-Fi, printers, password resets, device setup).

SmartDesk was built to:
- Reduce IT workload
- Help users resolve issues faster
- Provide 24/7 AI-assisted troubleshooting
- Scale across departments or organizations

---

## 🧠 How It Works

1. Users choose a category (Devices, Software, Accounts, or Other)
2. They select a specific issue (e.g., Laptop → Mac → Battery not charging)
3. SmartDesk automatically sends the issue to the AI
4. The AI returns clear, step-by-step troubleshooting guidance
5. If AI is unavailable, the app falls back to built-in Smart Replies

---

## 🛠 Technologies Used

**Frontend**
- JavaScript
- React Native (Expo)
- React Navigation

**Backend**
- Node.js
- Express.js
- REST API

**AI**
- OpenAI API (for AI-powered responses)
- Smart Replies (offline fallback logic)

**Storage & Auth**
- Firebase Authentication
- AsyncStorage (session and history management)

**Deployment**
- Render (backend hosting)

---

## 🔐 Security & Best Practices

- API keys are stored securely using environment variables
- No sensitive credentials are exposed in the repository
- Guest mode supported (no login required)

---

## 📱 Features

- AI-powered troubleshooting
- Category-based issue selection
- Auto-send issue from categories to chat
- Chat history with swipe-to-delete
- Guest mode and authenticated mode
- Offline Smart Replies fallback
- Auto-expanding chat input
- Cost-optimized AI usage
